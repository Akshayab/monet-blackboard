# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment, personal attacks and discrimination aren't tolerated in issues, pull
requests or any other project space. To report a conduct problem, use GitHub's private
vulnerability reporting form on this repository (it reaches maintainers only), or contact a maintainer directly.
Reports are kept confidential. For security issues, see [SECURITY.md](SECURITY.md).
